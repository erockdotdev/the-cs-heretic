## **The Hard Truth of Tech Interviewing:** [Start Here](interviewing-framework/README.md)

>
> The interview loop is a **standardized, >high-volume filtering system** optimized for:
>- Scalability
>- Consistency across interviewers
>- Legal defensibility
>- Low false-positive rate
>
>It is only weakly correlated with real on-the-job performance.  
>It strongly selects for people who have the time, energy, and willingness to study and rehearse the current set of approved performances.
>
